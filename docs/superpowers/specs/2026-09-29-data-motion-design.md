- 原型（已由用户选定）：`portfolio-site/.superpowers/brainstorm/1010-1790687193/content/data-motion-v7.html`（电影级粒子，调暗版）、`data-motion.html` 中的 A（机械计数）与 D（冲击排版 + 解码扫描）

## 1. 目标

让数据本身成为最吸引人的视觉：冲击力强，但不牺牲可读性、真实性和性能。

用户在原型阶段的决定：
- 四个方向都要，并要"更狠"；最终选定**电影级粒子**（20 万粒子、HDR 泛光、镜头穿越、冲击波、点击爆破），**亮度调低**（v7）。
- 放置方案由我决定（用户："看你的了"）。

成功标准：
- 打开进阶版，第一屏就是会动的数据场面；滚动四屏看完"5,142 笔订单 → 下单地形 → 商家收入"，每个数字都是真实查询结果。
- 在不支持 WebGL2、开了减少动态效果或设备太慢时，页面退回到安静、完整的静态版本，不留空白、不报错。
- 其他页面的数字动效不改变最终内容；测试照旧通过。

## 2. 放在哪里

| 效果 | 位置 | 说明 |
|---|---|---|
| 电影级粒子 | 进阶版页面开场（替换现在的点雨） | 约 4.5 屏高的滚动序章：星系 → 5,142 笔订单 → 镜头穿越 → 7×24 地形 → 12 家商家收入柱。之后是现有的六章叙事与驾驶舱，全部保留 |

| D 冲击排版 + 解码扫描 | SQL 页"从数字读出经营状态" | 4 个指标依次砸入、区块轻震、标签黑块刷出；商家与菜品两张表被红线扫过，数字从乱码解码成真值，首行红色标记 |

不动：首页开场与两扇门、档案补录页、影像区、CSV 页（已有清洗动画）。

## 3. 电影级粒子序章

### 3.1 视觉与交互（以 v7 原型为准）

- 状态：0 星系（三旋臂，缓慢自转）→ 1 "5,142" → 2 7×24 下单地形 → 3 商家收入柱（前三家红色）。
- 滚动位置映射为连续状态 0–3，逐帧平滑追随；往回滚倒放。
- 每个粒子带随机相位，在形状之间沿卷曲路径飞行；换场时镜头按预设路径俯冲、摆动（第 1→2 段穿过粒子云）。
- 每章成形时从中心荡开冲击波；点击画面在点击处爆破并弹回；拖动旋转视角；指针经过卷起漩涡。
- 渲染：粒子加色混合写入 HDR 缓冲 → 亮部提取 → 半分辨率与四分之一分辨率两级高斯模糊 → 合成（ACES 色调映射、边缘色散、胶片颗粒、暗角）。
- 亮度采用 v7 参数（桌面粒子增益 0.13、亮部阈值 0.45–1.6、两级泛光 0.5 / 0.8、曝光 0.9）。

### 3.2 文字与数字

- 章节字幕是真实 DOM 文本（屏幕阅读器可读），数字经 `InsightText` 渲染，来自 `deriveFacts`：`{orders}` 笔订单、前三家拿走 `{top3Share}`。
- 画布 `aria-hidden`；右上角技术角标（粒子数 · 帧率）是装饰，`aria-hidden` 并带 `data-insight-data`，不进入数字核对。
- 序章顶部提供"跳过序章"链接，直达摘要（键盘与读屏用户不必滚过四屏）。

### 3.3 性能与降级

| 条件 | 行为 |
|---|---|
| 桌面 | 200,000 粒子，完整泛光，画布分辨率上限 1.5 倍 |
| 窄屏（< 800px）或粗指针 | 50,000 粒子，关闭半分辨率泛光，分辨率 1 倍 |
| 运行时自适应 | 前 90 帧测平均帧率：低于 40 帧 → 绘制粒子数减半并关闭半分辨率泛光；低于 20 帧 → 退回静态 |
| 无 WebGL2、着色器编译失败、上下文丢失 | 退回静态 |
| `prefers-reduced-motion: reduce` | 直接静态，不创建 WebGL 上下文 |

**静态版本**：序章高度收缩为普通开场，显示巨字"5,142 笔订单"和副标题（与现在开场相同的文字与数字），不留下四屏空白滚动。

**加载顺序**：先渲染静态开场（首屏立即可读）；脚本在首帧后生成形状（放进 `requestIdleCallback`，不支持时 `setTimeout`），GPU 就绪后画布淡入、序章展开为滚动长度。

**代码体积**：原生 WebGL2，不引入第三方库；新增脚本预计 < 15 KB（gzip 前）。

### 3.4 移除

点雨开场（`rain.ts`、`rain-dom.ts`、对应单元与端到端测试、`InsightsHero.astro` 中的内联脚本）由序章取代并删除。

## 4. A 机械计数

- 每位数字是一条 0–9 × 3 的竖条，按位错开时间转到目标位，结束时带轻微回弹；非数字字符（逗号、¥、%、+）淡入。
- **最终 DOM 与原文一致**：动画期间原文在 `.sr` 里、滚轮 `aria-hidden`，容器带 `data-spinning`；结束后换回纯文本，移除属性。
- 快速概览页：数字进入视野时转动一次。
- 驾驶舱：筛选结果返回时，新值的每一位从当前位转到新位（位数变化时重新构建）；与现有"较新的结果作废旧动画"的规则一致。
- 减少动态效果：直接显示文字。

## 5. D 冲击排版 + 解码扫描（SQL 页）

- 指标：进入视野时 4 个数字依次从放大、模糊状态砸入（约 0.55 秒/个，间隔 0.4 秒），落地时所在区块位移 ≤ 6px 的短震，标签由黑块刷出。
- 两张表：一道红线从上往下扫过；扫过的行，含数字的单元格从乱码解码成原值，首行加一次红色标记。
- **最终 DOM 与原文一致**：解码完成后每个单元格的文字等于服务器渲染的原文。
- 减少动态效果：不做任何动画。

## 6. 模块划分

```
src/scripts/cinema/shapes.ts     纯函数：galaxy / textFromPixels / terrain / bars → Float32Array（位置、颜色），可注入随机数
src/scripts/cinema/camera.ts     纯函数：镜头关键帧、cam(state)（插值 + 俯冲 + 摆动）、stateFromScroll()
src/scripts/cinema/quality.ts    纯函数：particleBudget(width, coarse)、decideQuality(avgFps)
src/scripts/cinema/shaders.ts    着色器源码
src/scripts/cinema/renderer.ts   DOM/GL：上下文、缓冲、泛光管线、交互、失败回退
src/components/InsightsPrologue.astro   序章标记、字幕、静态开场、跳过链接
src/scripts/odometer.ts / odometer-dom.ts   机械计数（纯布局函数 + DOM）
src/scripts/impact.ts / impact-dom.ts       冲击排版与解码（纯函数 scrambleText + DOM）
```

## 7. 测试

**单元**
- 形状：粒子数正确；坐标有限且在预期范围内；同一种子结果相同；收入柱各柱粒子数与净收款成比例；地形各格高度与订单数成正比。
- 镜头：状态为整数时等于关键帧；0–3 之间连续；俯冲只在段中间出现。
- 质量：各宽度与帧率下的粒子预算与降级决定。
- 机械计数：拆位（数字 / 非数字）、每位目标偏移。
- 解码：`scrambleText(final, k, rand)` 保留非数字字符，k = 1 时恰为原文。

**端到端**
- 有 WebGL2 时：画布就绪（`data-ready`）、滚动改变序章章节、字幕数字等于查询结果、"跳过序章"可达摘要；无页面错误。无 WebGL2 的测试环境里此项跳过。
- 降级：用初始化脚本让 `getContext('webgl2')` 返回 null → 静态开场可见、序章不占四屏、无页面错误。
- 减少动态效果：静态开场，不创建画布上下文。
- 窄屏：粒子预算为 50,000（通过画布上的 `data-particles` 读取）。
- 快速概览页：动画结束后大数字文字为"2000"，没有残留的滚轮结构。
- 驾驶舱：现有"筛选后指标等于 SQL 结果"的测试不改断言照旧通过。
- SQL 页：动画后指标与表格文字与服务器渲染的原文一致；减少动态效果下无动画类。
- 全站现有测试照旧通过；数字核对排除 `[data-spinning]`（动画进行中的滚轮）。

## 8. 不做的事

- 不做声音。
- 不把粒子铺到首页或其他页面。
- 不引入 three.js 等第三方库。
