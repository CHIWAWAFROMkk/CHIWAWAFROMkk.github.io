## 3. 短片页（暗场）

页面结构，自上而下：

1. **开场**：标题 "Mais je t'aime · 可我还是爱你"、一句话故事、"全片只有一种红"、AI 生成与本人工作的分工说明。
2. **剪辑台**（`data-film` 区域，核心）：
   - 成片播放器（`film-60s.mp4`，海报帧 `film-60s.webp`，`preload="metadata"`，带声音、原生控件）。
   - 三条与成片同步的轨道，横向按 0–60 秒等比铺满：
     - **色带**：每 0.1 秒一格，取该时刻画面的平均颜色（600 格）。
     - **镜头轨**：22 个镜头块，按剪辑表起止时间排布；块上标镜头号与变速倍数（源时长 ÷ 槽位时长，保留一位小数，如 `1.5×`）；去色镜头灰色；叠化 / 闪黑在切点上画小标记；开头 0–2.17 黑场与 59.4 起片名各占一块浅色区。
     - **声波轨**：成片音轨每 0.1 秒的峰值（600 格），标出三个卡点：人声 0:12、枪响 0:44、反转 0:52。
   - 播放头（一条竖线）随 `timeupdate` 和 rAF 移动；点击任意轨道跳到对应时间。
   - 镜头块是按钮：点击后成片跳到该镜头起点，右侧（手机为下方）展开**镜头卡**：分镜视频循环（静音）、平台与第几次通过、审图要点；有返修记录的镜头显示"废稿 → 定稿"缩略图。左右方向键逐镜切换，焦点始终可见。
   - 镜头卡默认显示 S01；S02 不在镜头轨上，在轨道下方单独注明"S02 出片但未用于成片"，可点开看它的分镜视频。
   - 减少动态效果时：播放头只在 `timeupdate` 时跳动，不做 rAF 平滑；镜头卡的分镜视频不自动播放。
3. **先定规则，再出图**：BGM 与卡点、人物设定、道具连续性、审图方法（`.prose`）。
4. **四幕分镜**：现在 · 雨夜码头 / 过去 · 相爱 / 过去 · 背叛 / 现在 · 对峙与反转，每镜一张首帧定稿 + 说明；时间码改用剪辑表的真实时间。
5. **返修记录**：10 个镜头的废稿与定稿对比，每版被打回的原因。
6. **废片**：5 段失败的生成视频（点击播放）。
7. **工具与流程**、返回项目链接。

动效：只在剪辑台上；亮度克制，沿用暗场色板。色带本身就是画面的颜色，不加光晕。

## 4. 数据与生成

- `src/data/film-edit.ts`：从 `edit_60s.py` 逐行转录的剪辑表（镜头号、源文件名、入点、出点、成片起点、是否去色）与转场表，注明来源文件与行号；`stop` 取下一镜起点，最后一镜到 60.0。导出纯函数 `shotsWithStops()`、`speedOf(shot)`、`shotAt(t)`。
- `src/data/film.ts`：中英双语的镜头说明（标题、平台、第几次通过、审图要点、所属幕、返修版本）、规则文字、返修记录、废片说明；文字取自旧页，英文为本次翻译。
- `tools/film-signals.mjs`：用 ffmpeg 读取成片，输出 `public/media/mais-je-taime/film-signals.json`（`{ fps: 10, colors: ["#rrggbb", …600], peaks: [0–1, …600] }`）。颜色：`scale=1:1` 每 0.1 秒一帧取 RGB；峰值：单声道 8 kHz PCM 每 800 采样取最大绝对值并归一化。ffmpeg 路径取 `FFMPEG` 环境变量，否则用 `edit_60s.py` 里的 WinGet 路径。生成结果入库，构建时不运行 ffmpeg。
- 素材：从 origin/main 的 `assets/mais-je-taime/` 原样复制到 `public/media/mais-je-taime/`（首帧、`draft/`、`video/` 含成片与废片）。已存在的同名文件以 origin/main 版本为准（90cd241 更新过 `s19-end.webp`）。
- 事实清单 F8 改为成片完成状态（含"出片 23 段 / 成片用 22 段"），`SITE.projects` 中该项目的 `status` 同步；概览页放映厅胶片带补齐到出片的全部 23 段。

## 5. 隐私页

`/privacy/` 与 `/en/privacy/`，标注更新于 2026 年 10 月 2 日，按新站真实行为重写：

- **你输入的数据**：求职引擎、校园研究程序由 Pyodide 在浏览器内运行；CSV 工具、SQL 工作台在浏览器内处理；均不上传、不写入持久存储。
- **本地存储**：开场动画只在 `localStorage` 存一个"已看过"标记，用于下次跳过开场；可随时清除。
- **网站访问**：由 GitHub Pages 托管；本站目前没有访问统计、广告追踪、账号或支付。（运营任务接入统计时更新此段。）
- **作品与范例的边界**：样本与构造数据、求职引擎的虚构岗位与候选人、匹配分不是录用概率、QuotaDeck 为模拟数据且不读取访客设备或账号、AI 短片为 AI 生成画面。
- **外部链接与邮件**、联系邮箱（`SITE.email`）。

## 7. 测试

- 单元：剪辑表首尾相接、总长 60 秒、转场时间都落在某个切点上、去色标记与 `edit_60s.py` 一致（转录数据的快照比对）；`shotAt` 边界；`film-signals.json` 两个数组都是 600 项、颜色格式正确、峰值在 0–1。
- e2e（桌面 + 手机）：两种语言能打开；点镜头块后 `video.currentTime` 落在该镜起点 ±0.1 秒；播放后播放头位置随时间前进；方向键切换镜头卡；无障碍检查无 serious / critical；手机宽度无横向溢出；数字检查把 `[data-film]` 排除（时间码、倍数是标识，不是成绩）。隐私页纳入 `PAGES`。

## 8. 上线（用户已同意，在本地验收后执行）

1. 用户在本地预览两页并确认。
2. 在 scratchpad 中从 `origin/main` 开干净工作区；清空后放入 `dist/` 全部内容与 `.nojekyll`（否则 GitHub Pages 的 Jekyll 会忽略 `_astro/`）。
3. 提交（提交身份同仓库约定），普通推送到 `origin main`（快进，不强推）；源码分支 `redesign` 一并推送到 origin 备份。
4. 等 Pages 发布后逐个访问线上网址（第 6 节清单 + 新页面），确认 200 与关键内容。
5. 回滚：`git revert` main 上这一次提交并推送。
