让招聘方自己选择怎么看：想快速了解的，一分钟看完；想深入看的，或者在面试时现场演示，能看到每个项目的过程、在线演示和源码。整站重新设计，冲击力强但看不腻，中英双语同时上线。

## 6. 视觉系统

**颜色**（定义成全局变量，全站只引用变量）

| 名称 | 值 | 用法 |
|---|---|---|
| `--paper` | `#f2f1ec` | 默认背景 |
| `--ink` | `#0f0f0f` | 文字、1.5px 结构线、深色块 |
| `--mute` | `#6b6a64` | 次要文字（实现时实测对比度，必须 ≥ 4.5:1） |
| `--red` | `#e8380d` | 强调色，用于大数字和色面；每一屏最多一处 |
| `--red-text` | 实现时确定 | 红底白字的小号按钮用，加深到对比度 ≥ 4.5:1 |
| `--night` / `--night-fg` | `#0a0908` / `#ece4d6` | 暗场区；强调色仍用朱红，不引入琥珀色 |

**字体**

- 英文和数字的大号展示字：Barlow Condensed Bold（已自托管，OFL 许可），预加载。
- 中文大标题：系统粗体字体栈（`"PingFang SC","Microsoft YaHei UI","Microsoft YaHei",sans-serif`，字重 700/900）。
- 中文正文：沿用已经自托管、按 unicode-range 分片的 Noto Sans SC。

**版式**：全部直角，不用阴影、毛玻璃和呼吸点；用 1.5px 墨线和留白分区；12 栏网格。旧的装饰动效层（`reading-depth.*`、`motion.*` 里的背景元素）整体删除。

**动效**：只出现在四个地方：开场、两扇门出现和悬停变宽、大数字进入视野时上滑一次、列表行悬停反色。缓动曲线统一为 `cubic-bezier(.2,.8,.2,1)`，时长 200–700ms。`prefers-reduced-motion: reduce` 时关闭全部动效。不用视差，背景不做持续动画。

**图片**：删掉三张 AI 生成的场景配图（records-desk / analysis-desk / campus-courtyard）；项目配图用真实截图和重新上色的示意图 SVG；短片剧照保留。

**响应式**：先按 390px 设计。两扇门上下叠放，数字排成 2×2，项目列表缩成两列，表格可以横向滚动；页面本身不允许出现横向滚动条。

## 7. 首页：开场与两扇门

- **HTML 里默认就是两扇门的完整内容**，开场是由 JavaScript 叠在上面的一层。无 JavaScript、读屏软件、减少动态效果的访客和爬虫，直接看到两扇门。
- **开场时间线**（总长 ≤ 2.4 秒）：`2000`（名员工档案）→ `08`（张业务表）→ `23`（个镜头），各闪约 0.45 秒；朱红幕布从左扫满全屏；幕布上掀，露出两扇门，门上的大字上滑入场。
- **跳过**：点击、任意按键，或可见且可聚焦的「跳过」按钮。字体 0.8 秒内没加载完，就直接跳过开场。
- **再次访问**：用 `localStorage` 记住已经看过，之后只播 0.6 秒的大字入场；所有读写都包在 try/catch 里，存储不可用时当作首次访问处理。
- **两扇门**：01 精简版「1:00 / 一分钟看完」→ `/brief/`；02 深入版「ALL / 全部作品」→ `/projects/`。悬停或聚焦时对应的门变宽。
- **底部联系栏**：邮箱和「下载简历」，不选门也能直接拿到。

## 10. 双语

- Astro i18n：默认语言 `zh` 不加前缀，`en` 加 `/en/` 前缀，`trailingSlash: 'always'`。
- 短文字、数字、项目清单统一放在 `src/data/site.ts`，每个字段都是 `{ zh, en }` 对照，页面只从这里读取。
- 项目长正文放在 `src/content/projects/{zh,en}/<slug>.md`。
- 交互演示界面上的文字，通过同一份字典做双语。
- 英文文案由 Claude 翻译，上线前请用户过目。

## 13. 验收标准

1. `astro build` 零报错；站内链接检查全部通过；第 5 节列出的每个旧网址都能打开。
2. 每个页面在 390px 和 1440px、中英两种语言下截图，逐张检查：无横向溢出，无文字被遮挡。
3. axe 检查没有 serious / critical 级别的问题；只用键盘能走完"开场 → 门 → 精简版 → 项目页"，焦点始终可见。
4. 关掉 JavaScript 时首页显示两扇门；开启减少动态效果时没有动画。
5. 移动端 Lighthouse 性能分 ≥ 90；首页首屏的 JS ≤ 10KB（gzip 后）。
6. 功能实测：SQL 预设查询能出结果；CSV 内核的现有测试（`check.mjs`）通过；求职 Agent 范例正常显示；分镜播放器能连播；HRIS 演示四种结果都能走通。
