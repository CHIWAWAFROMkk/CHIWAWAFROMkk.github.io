## 1. 目标

让招聘方自己选择怎么看：想快速了解的，一分钟看完；想深入看的，或者在面试时现场演示，能看到每个项目的过程、在线演示和源码。整站重新设计，冲击力强但看不腻，中英双语同时上线。

设计优先级：**先让招聘方快速弄清"你是谁、能做什么、做了哪部分"，其次才是视觉效果。**

成功标准：
- HR 在手机上打开首页，**不点击任何东西**，就能知道姓名、主线、到岗信息，以及怎么联系。
- 30 秒内在快速概览里看到有明确含义的成果证据。
- 面试官从任意项目页开始，能看懂任务、个人贡献、AI 参与了哪些环节、有什么可以查证，并能亲手操作。

## 6. 视觉系统

**颜色**（定义成全局变量，全站只引用变量）

| 名称 | 值 | 用法 |
|---|---|---|
| `--paper` | `#f2f1ec` | 默认背景 |
| `--ink` | `#0f0f0f` | 文字、1.5px 结构线、深色块 |
| `--mute` | `#6b6a64` | 次要文字（实现时实测对比度，必须 ≥ 4.5:1） |
| `--red` | `#e8380d` | 强调色，用于大字和色面；每一屏最多一处 |
| `--red-text` | 加深到对比度 ≥ 4.5:1 为止 | 红底白字的小号按钮 |
| `--night` / `--night-fg` | `#0a0908` / `#ece4d6` | 暗场区；强调色仍用朱红 |

**字体**
- 英文和数字的大号展示字：Barlow Condensed Bold（已自托管，OFL 许可），预加载。
- 中文大标题：系统粗体字体栈（`"PingFang SC","Microsoft YaHei UI","Microsoft YaHei",sans-serif`，字重 700/900）。
- 中文正文：沿用已经自托管、按 unicode-range 分片的 Noto Sans SC。

**版式**：全部直角，不用阴影、毛玻璃和呼吸点；用 1.5px 墨线和留白分区；12 栏网格。旧的装饰动效层（`reading-depth.*`、`motion.*` 里的背景元素）整体删除。

**动效**：只出现在三个地方：首次访问的开场、大字进入视野时上滑一次、悬停反馈。悬停反馈只改变颜色、箭头位置和底色，**不改变元素尺寸和位置**，保证点击目标不会移动。缓动曲线统一为 `cubic-bezier(.2,.8,.2,1)`，时长 200–700ms。`prefers-reduced-motion: reduce` 时关闭全部动效。

**图片**：删掉三张 AI 生成的场景配图（records-desk / analysis-desk / campus-courtyard）；项目配图用真实截图和重新上色的示意图 SVG；短片剧照保留。

**响应式**：先按 390px 设计。两扇门上下叠放，表格可以横向滚动；页面本身不允许出现横向滚动条。

1. 满屏依次闪过 **DATA → AI → FILM**，各约 0.45 秒，下方中文小字「HR 数据 / AI 应用 / AI 影像」（英文站为 "HR data / Applied AI / AI film"）。

## 10. 双语

- Astro i18n：默认语言 `zh` 不加前缀，`en` 加 `/en/` 前缀，`trailingSlash: 'always'`。
- 事实放在 `src/data/facts.ts`；其他短文字放在 `src/data/site.ts`，每个字段都是 `{ zh, en }` 对照。
- 项目长正文放在 `src/content/projects/{zh,en}/<slug>.md`。

- 英文文案由 Claude 翻译，上线前请用户过目；英文文本普遍比中文长，布局按英文长度验证。

## 13. 分阶段验收

**第一阶段：打通一条完整的阅读路径**

范围：Astro 骨架、事实清单、视觉系统、首页（含开场）、快速概览、HRIS 项目页（含审核演示）、中英文简历下载，中英双语。

1. 路径"首页 → 快速概览 → HRIS 项目页 → 下载简历"在 390px 和 1440px、中英两种语言下都能走通，截图逐张检查：无横向溢出，文字无遮挡，英文长文本不破坏布局。
2. 首页不点击任何东西，就能看到姓名、主线、到岗信息和联系方式。
3. 只用键盘能走完整条路径，焦点始终可见；Esc 和跳过按钮都能跳过开场；Tab、Enter 不会误触发跳过。
4. 关掉 JavaScript 时首页完整显示；开启减少动态效果时没有动画；再次访问时没有入场动效。
5. 页面上每个数字都能在第 4 节找到对应的 `id`。
6. **第一阶段验收后交给用户确认方向，再进入第二阶段。**

**第二阶段：铺开全站**

2. 所有页面在 390px 和 1440px、中英两种语言下截图检查。
