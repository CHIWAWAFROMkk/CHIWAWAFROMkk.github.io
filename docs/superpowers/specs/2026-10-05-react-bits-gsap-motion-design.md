# 全站动效升级：React Bits + GSAP（设计）

日期：2026-10-05 · 状态：待用户审阅

## 1. 目标

在不破坏现有内容、性能与无障碍的前提下，把全站的动效与细节做得更精致：标题出场、滚动揭示、按钮手感、暗场质感统一成一套节奏；同时修掉 taste 审查清单列出的排版与交互细节。

成功标准：
- 视觉上：每页首屏有一个清楚的"出场"，往下滚有节奏地揭示，交互有反馈；整体仍然克制，不刺眼、不打断阅读。
- 技术上：现有端到端测试全部通过；每页布局跳动量低于 0.1；"减少动态"下所有内容立即可见；文字始终在静态 HTML 里；每页脚本体积有上限。

## 2. 已确认的决定（2026-10-05）

| 问题 | 用户选择 |
|---|---|
| 范围 | 全站（首页、概览、项目索引、各项目页、影像两页、隐私页） |
| React Bits 用法 | 引入 React，直接使用组件 |
| 强度 | 精致克制 |
| 设计做法 | 按需挂载的 React 组件 + 共用 GSAP（用户回复 "ok"） |

本设计**替换**总规范（2026-09-28）第 6 节里"动效只允许首访开场、大字上滑一次、悬停三处"的规定，以及 2026-10-01 的"效果削弱一档"在新增动效上的适用；亮度、闪光、震动等克制性规定继续有效。

## 3. 架构

- 新增依赖：`@astrojs/react`、`react`、`react-dom`、`gsap`、`@gsap/react`。GSAP 自 2025 年起完全免费（含 SplitText、ScrollTrigger）。
- React 只以"岛"的形式出现：组件包着服务端已经渲染好的文字（Astro 在构建时输出完整 HTML），浏览器端用 `client:visible`（滚动到附近才激活）或 `client:idle` 激活；页面其余部分保持纯静态。
- React Bits 组件以源码形式放入 `src/components/rb/`（与官方 ts-default 版本一致，保留其版权声明），按站点设计令牌做最小改动；改动处在文件头注明。
- 全站动效引擎：`src/scripts/motion/gsap.ts` 统一注册 ScrollTrigger、SplitText，导出动效令牌（时长、缓动、错落间隔）与"减少动态"判断。React 组件与现有原生脚本（荣格首屏、项目行出场等）都从这里取值，节奏一致。
- 不改动：各页的真实程序（CSV、SQL、求职引擎、QuotaDeck、校园统计、星图、电影剪辑台）及其脚本；它们不纳入 React。

## 4. 动效规矩（新）

- **令牌**：时长 0.2 秒（交互反馈）/ 0.6 秒（揭示）/ 0.9 秒（大标题）；缓动统一为 `cubic-bezier(.2,.8,.2,1)`（GSAP 中注册同名自定义缓动）；错落间隔 40 毫秒（字）/ 70 毫秒（行）/ 90 毫秒（块）。
- **只动 transform 和 opacity**，不动宽高与位置属性；出场前预留最终尺寸，不引起布局跳动。
- **亮度克制**：没有闪白、没有整屏变亮；暗场噪点不透明度不超过 0.06。
- **磁吸位移**不超过 6 像素，只用于主要行动按钮；触屏设备不启用磁吸与光斑。
- **减少动态**：所有组件直接显示最终状态，不创建 ScrollTrigger，不运行噪点动画。
- **帧率**：滚动中不出现长任务；ScrollTrigger 统一批处理，离屏不计算。

## 5. 选用组件与位置

| 组件（React Bits） | 用在哪里 | 说明 |
|---|---|---|
| SplitText | 首页姓名、各页 `h1`（概览、项目索引、项目页标题、隐私页） | 中文按字、英文按词拆分；只播一次 |
| ScrollReveal | 各页 `h2` 段落标题、项目页导语 | 滚动时由淡到实、轻微旋转归正；只播一次 |
| Magnet | 首页两扇门的箭头、"下载简历"、联系邮箱、荣格首屏按钮 | 位移上限 6 像素；不改按钮尺寸 |
| SpotlightCard | 项目索引与概览的项目行、影像区条目（暗场为浅光斑，亮场为极淡墨色光斑） | 光斑只改背景，不改尺寸位置 |
| Noise | 荣格页、电影页的暗场背景 | 静态颗粒为主，低帧率刷新（约 12 帧/秒），不透明度不超过 0.06 |

不选用：BlurText（需要额外的 motion 动画库）、需要可变字体的组件（站内字体不是可变字体）、大面积背景特效（Aurora、Ribbons 等，与"克制"冲突）。

## 6. 按 taste 清单修的细节

- 标题 `text-wrap: balance`，正文 `text-wrap: pretty`，避免孤字。
- 数字区域统一 `font-variant-numeric: tabular-nums`。
- 按钮与可点击行加按压反馈（按下时 `scale(0.98)`，0.12 秒）。
- 焦点框补齐所有可交互元素（含组件包裹后的元素）。
- 首屏类区块高度用 `svh`（小视口单位，地址栏伸缩时不跳动；`dvh` 会随地址栏变化而跳），现有首屏已是 `svh`，保持并在新组件中沿用。
- 宽屏版心统一（已修：项目列表行与 1600 像素版心对齐）。

## 7. 分批与上线

1. **门面页**：首页、快速概览、项目索引（含 React/GSAP 基础设施）。
2. **项目页**：五个数据项目页及其完整版、隐私页。
3. **影像两页**：荣格页、电影页（噪点、磁吸、标题）。

每批：单元测试与全站端到端测试通过 → 本机预览给用户 → 用户确认后上线（推 main，源码推 redesign）。

## 8. 验收与测试

- 现有全部测试照常通过（当前 634 项端到端、301 项单元）。
- 新增：每页布局跳动量低于 0.1（含滚动全页）；"减少动态"下所有文字可见、不创建 ScrollTrigger；关闭 JavaScript 时文字完整可读；React 只在用到组件的页面加载；每页首屏脚本体积上限（React 运行时 + 组件 ≤ 70 KB gzip）；磁吸与光斑在触屏模拟下不启用；axe 无严重问题。
- 手机（390 像素）与宽屏（1920 像素）截图检查。

## 9. 风险

- **水合闪动**：组件激活前后文字状态不一致会闪。对策：服务端输出的就是最终文字，激活后才把文字设为起始状态并立即播放；"减少动态"下不改动。
- **与现有动效重复**：项目行已有出场与悬停；改用组件后删除旧样式，避免叠加。
- **体积**：React 运行时约 45 KB（gzip）；只在门面页与项目页加载，影像页优先用原生脚本实现同类效果时也可接受。
- **许可**：React Bits 为 MIT + Commons Clause，允许用在网站中，不得单独出售组件；源码文件保留版权声明。

## 10. 不做的事

- 不把现有真实程序改写为 React。
- 不引入大面积背景特效、视差堆叠、平滑滚动接管（会影响阅读与无障碍）。
- 不改变信息结构与文案（本期只改表现层）。
