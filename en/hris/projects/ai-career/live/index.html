Job–Candidate Matching Engine (live edition)

The real matching engine, running in your browser.

In one minute

Problem & context
Let visitors edit the job description and the candidate themselves and watch the real engine judge, instead of a recorded result.
What I did
Set the demo's limits: the engine copied unchanged behind a thin bridge; the score rises to the raw total before the engine's own cap presses it down; the live source shows only lines that really ran.
Tools & AI
Built with AI coding tools; Pyodide runs Python in a Web Worker, and the runtime ships with the site — no third-party CDN.
What you can check
The live engine on this page, the per-file checksum manifests, the bridge code and its tests.
Status
Live edition · runs in your browser; nothing is uploaded and nothing is submitted.

Live engine: job agent matching

Public build 0.8.5 · 4397ded · running in your browser

Edit the job description and the fictional candidate; the real Python engine recomputes on the spot — it runs in your browser through WebAssembly, and nothing you type leaves your computer. The score rolls to the raw total the engine computed, then the engine's own cap rule presses it down; the "live source" panel lights the lines that just ran.
