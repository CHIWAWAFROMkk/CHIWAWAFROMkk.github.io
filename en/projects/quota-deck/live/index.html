QuotaDeck (live edition)

The real interface on a simulated clock: watch quota run out.

In one minute

The task
Let visitors see hours of quota change in seconds, and how QuotaDeck works out in advance when it will run out.
What I did
Set the demo's limits: the interface and the quota logic run unchanged, only the clock and the usage are simulated; the parallel run only walks the state flow and invents no answer.
Tools & AI
Built with AI coding tools; the main-process code runs unchanged in the page, and every account connector is replaced by one that refuses to read.
What you can check
The time machine on this page, the per-file checksum manifest and tests; the real desktop screenshots below.
Status
Live edition · runs in your browser; nothing on your computer or in any account is read.
