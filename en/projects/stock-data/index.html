What is this project?

The data checks from my earlier market-data project, turned into a light analysis tool anyone can try. The online version does general table checks and descriptive statistics — it is not a trading-strategy backtester. The diagram follows the tool’s steps: input, cleaning, statistics and export; the coloured table blocks only illustrate structure and are not extra data.

Current limits

No live market data, no Python, no calls to a large language model, and no guessing at business causes. The original market project still needs its raw data rebuilt before it can be recomputed, so no historical returns are presented as results of this tool.
