CSV 数据分析工具 · 版本 1.0.0 · [打开在线工具](/projects/stock-data/) · [下载源码包](/downloads/csv-lab-source.zip)

记录输入和清洗决策，再用公开样本与同一份计算代码检查输出。

## 项目目标

让查看作品的人可以带入自己的数据，核对处理前后差异，而不是只能看静态图表。

## 输入与输出

- 输入：带表头的 UTF-8 CSV、TSV 或粘贴文本；逗号、分号、制表符可自动识别。
- 输出：逐列质量检查、描述统计、直方图、可搜索排序的数据预览，以及 CSV 和 JSON 下载。

## 使用工具

JavaScript ES Modules 实现计算；File API 读取文件；Web Crypto 计算 SHA-256；HTML/CSS 显示表格和直方图；Node.js 运行同一模块及断言检查。无服务器端数据处理，无 AI 分析接口。

## 从输入到结果

1. **校验输入结构。** 先检查 2 MB、20,000 行、100 列上限；规范换行符并移除 UTF-8 BOM。自动识别表头中引号外的分隔符。解析双引号、转义引号和多行单元格。忽略整行空白；拒绝重复/空表头、未闭合引号和列数不一致的记录，避免静默错位。
2. **保留输入，记录处理影响。** 默认不删除记录。用户可选择先移除完全重复行，再移除含空白值的行。去重保留首次出现；比较原始单元格，不自动改写空格。每次从原始输入重新计算，可取消选项恢复。记录输入行数、两步移除数与输出行数，并检查它们能够对账。
3. **明确定义统计口径。** 空白与非数值不参与数值统计；严格接受十进制和科学计数法，拒绝无穷值、千分位文本及绝对值超过 10¹⁰⁰ 的数值。前导零编号推断为文本。均值为数值和除以有效数量；中位数与四分位数采用排序后线性插值；样本标准差分母为 n−1，只有一个值时不计算。
4. **呈现可核对的结果。** 直方图按等宽区间分箱，箱数为 min(10, ceil(√n))；相同值合为一个箱。区间左闭右开，最后一箱包含最大值，频数合计等于有效数值数量。低于 Q1−1.5×IQR 或高于 Q3+1.5×IQR 仅标为异常候选，不自动删除，也不解释为业务异常。
5. **导出复算依据。** JSON 保存计算模块版本、输入文本 SHA-256、分隔符、处理选项、行数审计和字段统计。用同一份输入、同一版本和相同选项可以复算。哈希用于比对内容，不证明数据来源真实。CSV 导出所有处理后记录，预览搜索与排序不影响导出。

## 验证结果

构造样本 · 非真实行情。样本使用两组虚构证券代码、日期、收盘价和成交量，共 13 行。其中 1 行完全重复、2 行各有一个空白值。

| 操作 | 预期结果 |
|---|---|
| 导入，不启用处理 | 13 行 / 2 个空白 / 1 行重复 |
| 启用完全去重 | 12 行 |
| 再移除含空白值的行 | 10 行 |
| 分析 close | 均值 15.2 / 最小 8 / 最大 22 |

### 为什么这些数值可信？

处理后 close 为：10, 11, 12, 9, 8, 20, 21, 22, 19, 20。合计 152，10 条有效记录，均值 15.2。网页与命令行导入同一个计算模块，不分别维护两份公式。

这验证的是确定性处理逻辑，不是市场收益，也没有宣称工具已经经过大规模用户验证。

## 自己运行

### 不写代码

1. 下载 [sample.csv](/assets/sample.csv)，打开[在线工具](/projects/stock-data/)上传。
2. 先核对 13 行、2 个空白和 1 行重复。
3. 勾选"移除完全重复行"与"移除含空白值的行"。
4. 选择 close，核对 10 行与均值 15.2。
5. 导出分析记录；取消选项，确认原始数据恢复。

### 在本地运行

下载[源码包](/downloads/csv-lab-source.zip)并解压，需要 Node.js 20.11 或以上版本。无第三方依赖，不必安装软件包。

```
node reproduce.mjs sample.csv --dedupe --drop-missing
node check.mjs
```

第一条输出结构化结果；第二条对核心样本、解析和统计执行检查。可把 sample.csv 换成你自己的文件。

## 过程与取舍

### 从行情报告到交互工具

原项目围绕行情清洗、SQLite 对账和策略资金账。由于原始 Excel 尚未补齐，不能重算真实市场结果。这个版本保留数据质量检查的思路，将通用部分独立成可公开体验的工具，不把未完成回测伪装成工具能力。

### 为什么在浏览器计算

轻量 CSV 不必先上传到后台，访客无需登录；输入仅保存在页面内存。代价是数据规模受限，所以明确限制大小、行列数，超过范围时停止并说明原因。

### 为什么不自动修复

空白可能有业务含义，离群值也可能是真实事件。默认只诊断；删除由使用者勾选，保留原始输入供恢复。涉及日期、货币、百分比、连接或回归等更复杂任务时，应使用专门分析流程。

### 下一步

尚未支持 XLSX、SQL、多表关联、持久保存和真实行情回测。后续扩展前先收集实际输入类型与使用反馈，避免界面出现尚未实现的按钮。
