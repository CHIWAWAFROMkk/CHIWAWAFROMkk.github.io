# CSV LAB 1.0.0

何彦钧作品集的数据分析工具复现包。sample.csv 是人工构造数据，不是真实行情。

需要 Node.js 20.11 或以上版本。解压后在此目录执行，无第三方依赖：

```
node reproduce.mjs sample.csv --dedupe --drop-missing
node check.mjs
```

预期：13 行输入，去重移除 1 行，空白过滤移除 2 行，10 行输出；close 均值 15.2。

analysis-core.mjs 与网页共用。默认不移除数据。空白为 trim 后为空，不把 NULL/NA 文本自动当缺失。
数值使用严格十进制/科学计数法解析，范围 ±1e100。百分比、货币、日期不自动转换。
分位数线性插值；标准差 n-1；IQR 异常候选不删除。输入最大 2 MB / 20000 行 / 100 列。
整行空白被忽略；重复表头、空表头、列数不匹配、异常引号会报错。
浏览器导出 CSV 时对可能执行公式的文本添加单引号保护；复算请使用原输入。
SHA-256 对输入解码后的文本计算，用来比对同一输入，不证明来源真实性。
工具不执行策略回测、不提供投资建议，也不自动得出因果或业务判断。
