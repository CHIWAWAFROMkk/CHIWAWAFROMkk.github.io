# 重新调查的问卷与分析口径

这是本次新设计的问卷，不是恢复的原问卷。以下为调查草案，正式发放前需填写研究负责人、联系渠道、保存期限，并按学校要求审查；本轮未对外发放。

## 开场说明

本调查了解成年在校大学生在过去 30 天主动使用 AI 工具的情况，参与自愿，可以不回答或退出。不收集姓名、学号、手机号、准确位置或对话中的敏感信息。回答仅用于本次研究；公开材料只呈现不能识别个人的汇总。这里的主动使用指你明确知道并主动调用的 AI 功能；不确定某个产品是否属于 AI 时请选择“不确定”，不要猜测。

## 题目

| 题号 | 问题 | 选项及跳转 |
| --- | --- | --- |
| Q1 | 是否愿意参加本次调查？ | 是 / 否；否则结束 |
| Q2 | 是否已满 18 岁且目前在校就读大学？ | 是 / 否；否则结束 |
| Q3 | 过去 30 天你是否主动使用过明确属于 AI 的工具？ | 是 / 否 / 不确定 |
| Q4 | 过去 30 天大致在哪些天数使用过？ | 1–3 天 / 4–15 天 / 16–30 天；仅 Q3 是填写 |
| Q5 | 过去 30 天在哪些场景主动使用过？ | 多选：学习；校园事务；社团活动；日常生活规划；求职；其他。可跳过。仅 Q3 是填写 |
| Q6 | 就这些实际体验而言，AI 对完成任务有多大帮助？ | 1 完全没帮助 / 2 帮助较小 / 3 一般 / 4 比较有帮助 / 5 非常有帮助；可跳过 |
| Q7 | 对 AI 输出中的重要事实，你通常多久会查验一次？ | 1 从不 / 2 很少 / 3 有时 / 4 经常 / 5 每次；可跳过 |
| Q8 | 如未使用或不确定，主要原因是什么？ | 开放题，可跳过；不纳入当前自动统计，不收集账号或敏感信息 |
| Q9 | 请举出一次有帮助或出错的实际任务，说明你如何检查。 | 开放题，可跳过；不得粘贴他人隐私或未获许可材料 |

Q6 和 Q7 的“可跳过”均记为缺失，而不是中间分值。Q3 否或不确定时，Q4–Q7 均为不适用。开放题由研究者脱敏后单独编码，不能直接把人物、经历或意见上传到公开页面。

## JSON 输入格式

一个文件为一个数组，一条记录代表一名匿名受访者的一次回答。`input_template.json` 只提供空数组，避免把示例误当已回收数据。

| 字段 | 类型 / 值 | 说明 |
| --- | --- | --- |
| respondent_id | 非空字符串 | 匿名随机编码；不使用学号、手机或姓名 |
| collected_on | YYYY-MM-DD | 实际填写日期；不能以原项目年份替换 |
| consent | true / false | Q1 |
| eligible | true / false | Q2 |
| used_ai | yes / no / unsure | Q3，符合纳入条件的记录必填 |
| frequency | 1_3 / 4_15 / 16_30 / null | Q4；使用者必填；非使用者必须 null |
| scenarios | 字符串数组 / null | Q5；取值 study / campus / club / daily / career / other；未答为 null，已答不能空数组 |
| helpfulness | 1–5 整数 / null | Q6；缺失为 null |
| verification | 1–5 整数 / null | Q7；缺失为 null |

不纳入程序的开放题另存去标识材料，不加入上述记录。程序对未知字段直接报错，减少意外携带私人字段的风险；这不是自动脱敏保证，导入前仍须人工审查。未同意或不符合人群条件的记录会先被排除，不统计其评价。

## 清洗与统计

1. 检查 JSON 数组及字段结构。错误类型、非法枚举、越界评分、逻辑矛盾直接报错，不静默修复。
2. 相同 respondent_id 出现多次时全部隔离；输出重复 ID 组数和排除行数，不输出 ID 本身。
3. 按顺序排除重复 ID、未同意、不符合人群、采集窗口外记录。每行只计入一个主排除原因，因此排除计数可相加。
4. 保留题项缺失，不插补。总体纳入人数与使用者人数分别输出。
5. 主动使用比例 = Q3 是人数 / 纳入人数；同时列出否与不确定人数，解释“不确定”的影响，不称为全面 AI 渗透率。
6. 场景比例 = 选择该场景的使用者数 / 回答 Q5 的使用者数；所有场景使用同一分母，多选总和可超过 100%。
7. 有帮助程度和核验频率分别计算有效回答数、缺失数、1–5 分频数与中位数。二者不是同一个量表，不合并成“AI 素养分”。
8. 使用频率组只输出人数和有帮助程度的描述统计，不输出显著性、因果结论或校园总体推断。小分组未经再识别审查不公开。

程序保存输入文件 SHA-256 以识别是否使用同一份输入；文件哈希不能证明输入真实。没有数据时比例与中位数输出 null，绝不把“没有观测”表示成真实的零使用率。
