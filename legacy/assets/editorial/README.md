## Diagram mapping

- `csv-process.svg`: input, quality checks, transformation history, analysis output.
- `career-evidence.svg`: documented facts, unknown facts, drafts and human review.
- `campus-method.svg`: questions, evidence, task experiments and feedback.
- `delivery-relations.svg`: simplified order-centred entity relationships, not the full SQL schema.
- `hris-flow.svg`: employee list, document evidence, candidate fields, review and recording.
- `quota-pools.svg`: shared provider quota sources, model directory and independent task roles.

Raster files are 1536 × 1024. Below-the-fold images use native lazy loading with explicit dimensions. The home hero uses a single image background; text remains real HTML. Diagrams are scalable SVG images with alt descriptions and scrollable viewports on narrow displays.
